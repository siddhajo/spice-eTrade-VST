Spice eTrade — printing app

Install this on the phone that prints to the Bluetooth thermal printer.
1. Download & install
⬇ Download app
  1. Tap Download app above.
  2. Open the downloaded spice-etrade.apk.
  3. If asked, allow “install from unknown sources” for your browser — then tap Install.
This is your own company app — the “unknown sources” warning is normal for apps not from the Play Store.
2. Pair the printer (once)
  1. Android Settings → Bluetooth → pair your thermal printer.
  2. If Android asks for a PIN, most of these printers use 0000 or 1234.
3. Set it up in the app (once)
  1. Open Spice eTrade, log in.
  2. Menu (⋮) → Print method → cycle to Bluetooth (app).
  3. Menu → Connect Bluetooth printer → pick your printer.
  4. Allow “Nearby devices” when Android asks.
  5. Menu → 🧪 Test print → a small “PRINTER OK” slip should print.
Done — receipts now print straight to the printer. No RawBT, no watermark. When the app updates, you don’t need to reinstall; just reopen it.
